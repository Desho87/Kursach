\# Keyboard Interceptor



Курсовой проект на языке программирования Rust. Программа предназначена для демонстрации обработки клавиатурных событий в графическом интерфейсе.



\## Возможности



\- Запуск и остановка регистрации клавиатурных событий.

\- Отображение событий нажатия и отпускания клавиш.

\- Отображение идентификаторов клавиш.

\- Отображение временных меток событий.

\- Отображение состояния повторного нажатия.

\- Запись информации о событиях в файл `keyboard\_log.txt`.



\*\*Важно:\*\* программа обрабатывает клавиатурные события только в собственной тестовой области, когда окно приложения находится в фокусе. Она не записывает текст, вводимый в других приложениях.



\## Используемые технологии



\- \*\*Rust\*\* — основной язык программирования.

\- \*\*egui / eframe\*\* — создание графического интерфейса.

\- \*\*Chrono\*\* — работа с датой и временем.

\- \*\*Cargo\*\* — управление проектом и сборка.



\## Требования



\- Windows 10 или Windows 11.

\- Установленный Rust и Cargo.

\- Инструменты сборки Visual Studio C++ для Windows.



\## Сборка проекта



Откройте командную строку в папке проекта и выполните:



```bash

cargo build --release

```



\## Запуск проекта



Для запуска через Cargo:



```bash

cargo run --release

```



После сборки исполняемый файл находится здесь:



```text

target/release/keyboard\_interceptor\_rust.exe

```
